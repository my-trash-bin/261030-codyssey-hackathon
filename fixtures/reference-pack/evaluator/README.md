# 평가자 전용 자료

이 디렉터리는 평가자 역할에게만 제공한다. 생성 앱/LLM/작성/검토 도구의 mount, 검색 루트, 파일 선택 기본 목록, 도구 입력에서 제외한다. 경로 이름에만 의존하지 않고 실제 접근 목록을 제한한다.

- `expected/`: 각 평가 사례의 허용/금지/필수 의미 정답표. 앱이 이 파일을 읽으면 평가 정답을 미리 알고 결과를 맞추는 것이 되므로 접근을 허용하지 않는다.
- `heldout/`: 아직 구현에 사용하지 않은 변형 계획. 구현 동결 뒤 공개한다. 현재 패키지에 미공개라고 주장할 사례를 미리 넣지 않는다.

옛 `evaluation/expected/`, `evaluation/heldout/`에서 옮겨왔다. 실제 실행 보고(`evaluation/results/`)와 3자 비교 실험 도구는 더 이상 저장소에 두지 않으며, 평가자가 필요할 때 로컬에서 별도로 구성한다.
