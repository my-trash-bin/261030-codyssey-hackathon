# 작성자용 가상 자료

이 디렉터리의 회사/고객/제품/사업 정보는 모두 가상이다. 비밀 표식은 `DEMO_ONLY_SECRET_*` 형태의 무효 문자열이며 실제 인증 정보가 아니다.

사용자가 선택한 해당 작업의 파일만 앱에 넣는다. 자료를 넣는 행위는 공개 승인이 아니다. `../recipient`와 `../../evaluation` 자료는 앱/LLM/작업 도구에게 제공하지 않는다.

기대 결과와 결정 계획은 [test-data.md](../../../docs/test-data.md)에 정의한다. 최종 출력 문장과 재현 결과를 이 입력 파일에 정답으로 넣어 학습/생성시키지 않는다.
