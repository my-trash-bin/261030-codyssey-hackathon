연결 확인 전

이 화면에서 실제로 연결된 기능

  • GET /api/core — 실행 모드·연결 방식·준비 상태 설정 조회
  • GET /api/documents — 저장된 내부 텍스트 조회
  • POST /api/documents — 내부 텍스트 저장

연결되지 않은 기능

  • 내부 근거·검토·이력 조회, 스킬 등록
  • 원자료 파일 업로드와 자료 분석
  • POST /api/sharing 호출과 승인 결정 저장
