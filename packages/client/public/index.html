파일 첨부 · 연결 대기

파일 업로드 기능이 아직 연결되지 않아 파일을 선택할 수 없습니다.

내부 메모 저장은 파일 분석과 별개의 기능입니다.

공유 초안

아직 공유 초안이 없습니다.

승인된 정보로 작성한 본문·표·첨부가 표시되는 자리입니다. 현재는 작성 기능이 연결되지 않았습니다.

공개 결정 저장과 초안 작성 기능이 아직 연결되지 않았습니다.

파일 확인·확정 기능이 아직 연결되지 않았습니다.

내부 근거와 검토

내부 참고용입니다. 공유 파일에는 포함되지 않습니다.

근거

후보별 인용 근거는 공개 결정 영역의 각 후보에 표시됩니다. 후보를 조회하지 못했거나 task 응답에 근거가 없으면 여기에는 아무것도 표시하지 않습니다.

검토

검토 기록 API가 연결되지 않아 검토 기록이 없습니다.

이력

판본·이력 API가 연결되지 않아 이력이 없습니다.

스킬 등록 기능이 아직 연결되지 않았습니다.

주요 동작

자료 분석 기능이 아직 연결되지 않았습니다.

내부 텍스트 보관

내부 텍스트 보관일 뿐이며 자료 분석·공개 승인·공유 초안 생성이 아닙니다.

내부 메모 작성

비어 있는 텍스트는 저장할 수 없습니다.

저장된 내부 문서

내부 텍스트 보관 목록입니다. 공유 결과나 승인 기록이 아닙니다.

저장된 문서를 불러오는 중입니다.

실행 정보

위쪽 모드 표시는 GET /api/core의 설정 상태이며 모델 호출 성공을 뜻하지 않습니다. 확인에 실패하면 모드나 연결 방식을 추정해 표시하지 않습니다.

실행 환경 상태

연결 확인 전

실행 환경을 확인하는 중입니다.

이 화면에서 실제로 연결된 기능

  • GET /api/core — 실행 모드·연결 방식·준비 상태 설정 조회
  • GET /api/documents — 저장된 내부 텍스트 조회
  • POST /api/documents — 내부 텍스트 저장
  • GET /api/v1/tasks/{id} — 공개 결정 화면의 task 집계 조회(계약에 정의됨, 서버 라우트가 없으면 404 오류로 표시)

연결되지 않은 기능

  • 공개 미리보기·결정 배치 저장·결정 철회·직접 입력 조건 해석 — 화면과 전송 경계만 있고 서버 라우트가 없어 요청이 오류로 끝납니다
  • 공유 초안 생성·확정·다운로드
  • 내부 검토·이력 조회, 스킬 등록
  • 원자료 파일 업로드와 자료 분석
  • POST /api/sharing 호출
