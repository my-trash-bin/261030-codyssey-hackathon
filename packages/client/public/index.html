로컬 접속

서버를 시작할 때 설정한 운영자 토큰으로 세션을 엽니다. 토큰은 이 화면의 메모리에만 쓰고 저장하지 않습니다. 세션은 1시간 뒤 만료되며, 만료되면 다시 입력해야 합니다.

세션 상태를 확인하는 중입니다…

작업 만들기

목적·수신처로 작업을 만들고 원자료를 그 작업의 첫 판본으로 등록합니다. 형식은 txt·log·md·csv·json(UTF-8), 파일당 256 KiB, 합계 1 MiB까지입니다.

세션을 열면 작업을 만들 수 있습니다.

전달 조건

목적·수신처는 서버에 저장되지 않습니다. 다만 분석을 실행하면 선택한 파일과 함께 분석 요청 본문에 담겨 설정된 분석 모델로 전송됩니다.

파일 분석 · 내부 근거

공유 초안

아직 공유 초안이 없습니다.

승인된 정보로 작성한 본문·표·첨부가 표시되는 자리입니다. 현재는 작성 기능이 연결되지 않았습니다.

공개 결정 저장과 초안 작성 기능이 아직 연결되지 않았습니다.

파일 확인·확정 기능이 아직 연결되지 않았습니다.

내부 근거와 검토

내부 참고용입니다. 공유 파일에는 포함되지 않습니다.

근거

파일 분석으로 받은 내부 근거와 후보 제안은 위의 분석 결과 영역에 표시됩니다. 여기는 공개 결정 영역의 task 후보 인용 근거 자리이며, 후보를 조회하지 못했거나 task 응답에 근거가 없으면 아무것도 표시하지 않습니다.

검토

검토 기록 API가 연결되지 않아 검토 기록이 없습니다.

이력

판본·이력 API가 연결되지 않아 이력이 없습니다.

스킬 등록 기능이 아직 연결되지 않았습니다.

주요 동작

파일·목적·수신처와 승인 환경 확인 동의가 필요합니다.

내부 텍스트 보관

내부 텍스트 보관일 뿐이며 자료 분석·공개 승인·공유 초안 생성이 아닙니다.

내부 메모 작성

비어 있는 텍스트는 저장할 수 없습니다.

저장된 내부 문서

내부 텍스트 보관 목록입니다. 공유 결과나 승인 기록이 아닙니다.

저장된 문서를 불러오는 중입니다.

위쪽 모드 표시는 GET /api/core의 설정 상태이며 모델 호출 성공을 뜻하지 않습니다. 확인에 실패하면 모드나 연결 방식을 추정해 표시하지 않습니다.

실행 환경 상태

연결 확인 전

실행 환경을 확인하는 중입니다.

이 화면에서 실제로 연결된 기능

  • GET /api/core — 실행 모드·연결 방식·준비 상태 설정 조회
  • POST /api/analysis — 선택한 파일의 내부 근거·후보 제안 요청(분석 응답이며 공개 허가가 아닙니다)
  • GET /api/documents — 저장된 내부 텍스트 조회
  • POST /api/documents — 내부 텍스트 저장
  • GET /api/v1/tasks/{id} — 공개 결정 task 집계 조회(인증된 세션 필요, API 비활성·미인증·작업 부재를 오류 코드로 구분)

이 화면에서 확인할 수 없는 것

  • 분석에 쓰이는 실제 모델의 주소와 그 모델이 승인된 사내·로컬 환경인지 여부 — GET /api/core는 구현·연결·준비 상태만 알려줍니다
  • 분석 결과의 저장 여부·공개 허가 여부 — 분석 응답은 이 화면 안에서만 쓰이고 저장되지 않습니다

연결되지 않은 기능

  • 공개 미리보기·결정 배치 저장·결정 철회·직접 입력 조건 해석 — 서버 API는 제공되며 화면 로그인·CSRF 토큰 전달 연결은 후속입니다
  • 공유 초안 생성·확정·다운로드
  • 내부 검토·이력 조회, 스킬 등록
  • 원자료 파일의 서버 저장 — 파일은 분석 요청 본문으로만 쓰이고 보관되지 않습니다
  • POST /api/sharing 호출
