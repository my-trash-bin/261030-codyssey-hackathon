# UI와 API 연결 현황

현재 HTTP 계약은 [API 문서](../design/api.md), 제거 기능과 추가 후보는
[기능 정리](../product/deferred-features.md)를 정본으로 삼는다.

- 세션은 화면에서 자동 생성·복원한다. CSRF와 Host/Origin 검증은 유지한다.
- 작업은 intake로만 생성한다. 목적은 서버 선택지, 수신처는 직접 입력하며 사전 등록을 요구하지 않는다.
- 원자료 등록·교체·해제와 분석 job 시작·조회·취소, 수동 후보 추가를 연결한다.
- 필드 선택과 미리보기, 공개 결정 배치와 철회를 연결한다. 모델 제안은 공개 허가가 아니다.
- 초안 생성·자동 검토·사람 검토·확정·동일 bytes 다운로드를 연결한다.
- 작업 목록·삭제와 이벤트 이력을 연결한다.
- 메모 보관함, 구형 context 생성, 독립 분석, 세션 조작, JSON 편집,
  규칙 관리와 실행 환경 화면은 제거했다. 실제 앱에서 제거된 경로는 404 또는 405를 반환한다.
- 재사용 규칙의 서버 계약과 정합성 검증은 유지하지만 별도 관리 화면은 제공하지 않는다.
- 합성 재현 엔진은 남아 있으나 작업 화면의 목표 선택지에는 노출하지 않는다.

## 지원 한도

선택 필드는 단일 CSV/JSON의 검증된 근거 범위에서만 사용할 수 있다.
방향·인덱스 변환은 단일 CSV 숫자 열만 지원한다. 승인 발췌와 타임라인 표현은 미지원이다.
원자료·근거 개수, 파일 크기, 모델 입력·재시도 예산은 서버 제한을 따른다.
브라우저 해시는 secure context가 필요하다. 외부 모델 품질 검증과 합성 회귀를 구분한다.

결정적 회귀는 `packages/core/src/disclosure.test.ts`,
`packages/server/src/workflow-http.test.ts`, `packages/app/src/lifecycle.test.ts`에서 확인한다.
fake-app의 문서/공유 API는 연출 전용이며 실제 앱의 대체 경로로 사용하지 않는다.
