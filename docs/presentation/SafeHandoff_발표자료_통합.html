프로젝트 배경: 외부에 물어야 일은 풀리는데, 그대로 보내면 유출이 된다

01 / PROJECT BACKGROUND

실제 보안 사고 뉴스와 기업 데이터 반출 조사에서 확인한 세 가지 배경

배경 1 · 현실의 기밀 유출 사고

급한 오류·회의록을 외부에 묻다
회사 기밀이 유출된다

회사 데이터 외부 AI 입력 1년 새 485% 폭증
삼성전자 반도체 부문 코드·회의록 유출 3건 발생

  • 당장 급한 오류를 고치려 소스코드 전체를 복붙하고, 비공개 회의록을 통째로 넣어 요약을 맡겼다가 핵심 기밀이 외부 서버로 유출됨
배경 2 · 막아도 쓰게 되는 현실

유출이 두려워 회사에서 막아도,
당장 급한 직원은 몰래 복붙한다

기업 보안 우려 1위 ‘민감 정보 유출’(64.5%)
하지만 개인 계정으로 몰래 쓰는 비율은 73.8%

  • 외부에 가장 많이 복붙하는 자료는 ① 고객지원 문의(16.3%) ② 소스코드(12.7%) ③ 내부 문서(10.8%) 순으로, 회사에서 막아도 일을 해결하려 몰래 보내게 됨
배경 3 · 이름만 가리는 방식의 한계

이름·번호만 지워선 비밀이 새고,
너무 많이 지우면 대화가 안 된다

덜 가리면 주변 내용으로 회사 정보가 드러나고
너무 많이 가리면 앞뒤 맥락이 깨져 이해 불가

  • 이름·연락처만 가리면 주변 내용과 합쳐져 회사 정보가 드러나고, 반대로 너무 많이 지우면 앞뒤 맥락이 끊기며 사람이 일일이 찾아 고치는 데 큰 시간이 듦

타겟 페르소나: 외부에 도움을 청할 때마다, 회사 자료를 일일이 가리고 다시 쓰느라 지친 실무자

02 / TARGET PERSONA
서비스 운영·기술지원 담당 · 핵심 사용자

박지훈 31세 · 남

IT 서비스 기업 운영·기술지원 담당 (4년 차)

회사 보안 때문에 외부 AI·고객센터에 원본 첨부 금지

매달 외부 업체에 오류 문의·업무 자문을 요청함

보내야 할 자료: 업무 현황표 · 회의 메모 · 오류 화면

가려야 할 정보: 거래처 이름 · 단가 · 건수 · 회사 코드

원본 첨부 금지 일일이 손으로 가림 매달 외부 문의
“외부에 물어봐야 당장 막힌 일이 풀리는데, 원본을 그대로 보내면 보안 사고고 하나하나 지우다 보면 설명이 빠져서 두세 번씩 다시 써야 해요.”

페인 포인트 (Pain Points)

  • [손으로 가리는 시간 낭비] 회사 파일을 외부 AI나 고객센터에 그대로 보낼 수 없어, 사람이 일일이 거래처·숫자·주소를 찾아 지우고 문장을 새로 쓰느라 시간을 다 쓴다
  • [이름만 지워도 티 나는 회사 비밀] 이름·전화번호만 가려도 오류 기록의 작업 이름이나 단가 비율에서 우리 회사의 영업 방식과 규모가 드러날까 봐 어디까지 보여줄지 매번 고민한다
  • [너무 많이 지우면 대화가 안 됨] 겁이 나서 숫자와 설명을 다 지워버리면, 정작 상대방이 오류를 확인하지 못하거나 중요한 조건(“기존 접수 채널 유지”)을 놓쳐서 두세 번 다시 설명해야 한다
  • [고칠 때마다 반복되는 수작업] 로그를 고칠 때마다 관련된 설명 내용도 일일이 맞춰서 다시 수정해야 하고, 다음번에 비슷한 로그를 보낼 때도 처음부터 똑같은 작업을 반복한다

니즈 및 목표 (Needs & Goals)

  • [수준만 고르면 알아서 가림] 원본은 회사 안에서만 읽고, 어디까지 보여줄지 공개 수준(A~D)만 고르면 AI가 알아서 일정 부분을 가려주면 좋겠다
  • [AI 수정 로그를 사람이 확인] AI가 가려야 할 부분을 가린 ‘수정 로그’를 만들어 보여주면, 제대로 가려졌는지 사람이 한눈에 확인하고 싶다
  • [규칙 보완 및 로그·설명 수정] 부정확하면 사람이 규칙을 수정·추가해 다시 돌리고, 정확하면 로그 파일과 그에 관한 설명 내용까지 한꺼번에 수정되면 좋겠다
  • [스킬 등록으로 다음 작업 자동화] 확인이 끝난 처리 기준(어떤 경우에 어느 정도로 가릴지)을 ‘스킬(Skill)’에 등록해 두고, 다음번에는 자동으로 처리하고 싶다

외부 공유 자료 준비 User Flow

자료 입력 → 공개 수준(A~D) 선택 → 결과 확인 후 맞으면 다음 단계(저장·스킬 등록), 아니면 규칙 설정으로 복귀

핵심 기술Core Technology & Stack

프론트엔드 워크스페이스 · 백엔드 & AI 서빙 엔진 · 데이터베이스 및 보안 격리 인프라

프론트엔드

Client · View

React / Vite / TypeScript

5단계 공유 자료 준비 워크스페이스 구현에 빠른 번들링(Vite) + 정적 타입 검사(TypeScript) 조합을 활용해 개발 생산성과 코드 안정성을 동시에 확보했습니다.

TailwindCSS / UI 컴포넌트

유틸리티 클래스 스타일링과 디자인 토큰을 적극 활용해 공개 수준(A~D) 비교 카드와 실시간 미리보기 화면을 일관되고 신속하게 구축했습니다.

단일 상태 트리 · 동시 갱신

공개 수준(A~D)이나 직접 입력(D) 조건을 바꿀 때 연결된 본문·표·설명의 수치가 어긋나지 않도록 직관적인 전역 상태 접근 및 즉시 동기화를 구현했습니다.

근거 하이라이트 & 반출 뷰어

외부에 보낼 공유 초안 문장과 사내 원본 문서(운영메모.md)의 근거 위치를 시각적으로 분리 표시해 실무자가 유출 여부를 한눈에 검증하도록 완성했습니다.

백엔드 & AI 엔진

Controller · AI Engine

TypeScript API / FastAPI 서빙

MVC 구조의 백엔드 컨트롤러(Route·Service·Repository)와 비동기 AI 추론 서빙(FastAPI)을 결합해 로그 분석·비식별화·스킬 매칭 응답 지연을 최소화했습니다.

LLM API · Gemini / 사내 sLLM

모델 교체형 추론 인터페이스를 적용해 상용 LLM API(Gemini·OpenAI)뿐 아니라 망분리 환경의 사내 경량 모델(sLLM)도 코드 수정 없이 즉시 연결합니다.

CaMeL 원문 격리 & 비식별 변환 엔진

원문 접근을 차단하고 승인된 사실만 주입하는 CaMeL 권한 분리 구조와 공개 수준(사실·추이·비율·마스킹) 변환 엔진을 직접 개발해 원본 숫자 노출을 원천 방지합니다.

PyTorch / 3-Way 의미 대조

유사 문제 분류와 원문·선택 기준·초안 3자 의미 대조 검증을 수행하여, 비식별화 과정에서 빠진 필수 업무 제약(“기존 접수 채널 유지”)을 자동 복원합니다.

데이터베이스 & 인프라

Model · DevOps

PostgreSQL / Prisma ORM

로그 분석 이력, 공개 수준(A~D) 승인 내역, 문장별 사내 근거 매핑 메타데이터를 정형 관계형 스키마와 타입 안전 ORM으로 일관되게 관리합니다.

Skill Repository (스킬 저장소)

사용자가 확인·승인한 가림 기준(목적·수신처·조건 → A~D 규칙)을 스킬로 저장소화하여, 반복 작업이나 타 기업 유사 문제 해결 시 즉시 재사용합니다.

Auth & Tenant / RLS 원문 격리

기업 A·기업 B 간 테넌트 권한 분리와 Row-Level Security(RLS)를 적용해 사내 원본 로그는 격리하고 승인된 스킬만 안전하게 공유합니다.

GitHub CI/CD · On-Prem / Cloud

PR 단위 Preview 검증과 main 브랜치 자동 빌드·배포 파이프라인을 구축했으며, 기업 보안 정책에 따라 사내 구축형(On-Prem)과 클라우드를 모두 지원합니다.

서비스 확장 계획: 타겟 시장(TAM-SAM-SOM) 로드맵

실제 적용 가능성(사내 AI 즉시 연동·전사 확산)과 3단계 추가 개발 방향
Phase 1. 단기 (SOM)

사내 AI·망분리 환경을 운영 중인 국내 IT·금융 기업

규모: 360억 원
  • 타겟 및 적용: 기존 사내 AI·경량 공개 모델(sLLM)에 추가 장비 없이 즉시 연결 (약 1.5만 개사)
  • 근거 및 개발: 15,000개사 × 연 240만 원 (월 20만 원 구독) · 공개 수준(A~D) 초안·검토·스킬 자동화
Phase 2. 중기 (SAM)

외부 기술 문의·자문이 빈번한 국내 전체 중소·중견기업

규모: 3,600억 원
  • 타겟 및 확산: 개발팀(오픈소스 제보)부터 운영·재무팀(정산·컨설팅 자문)까지 전사 확산 (약 15만 개사)
  • 근거 및 개발: 150,000개사 × 연 240만 원 · 제품별 제보 양식팩, 문맥 예외 판별, 대용량 고속 검색
Phase 3. 장기 (TAM)

글로벌 기업용 AI 데이터 보안 · 외부 협업 SaaS 시장

규모: 약 4.2조 원
  • 타겟 및 확장: 아시아 및 글로벌 B2B 기술지원 · 기업용 생성형 AI 반출 통제(DLP) 시장 확장
  • 근거 및 개발: 국내 유효 시장의 약 12배 규모 환산 · 합성 예제 자동 실행 검증 및 지원 티켓 원스톱 연동
* 시장 규모 추정: 기업용 SaaS 구독료(월 20만 원) 기준 하향식(Bottom-up) 재산출 / 국내 ICT·정보보호 기업 통계 및 글로벌 AI 보안(DLP) 시장 기준 확장 원칙: 공개 범위는 항상 사용자가 결정 · 준비된 업무부터 단계적 연결
